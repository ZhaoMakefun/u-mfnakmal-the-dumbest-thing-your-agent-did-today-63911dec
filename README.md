# The Dumbest Thing Your Agent Did Today

One true-feeling line from a real working day: an agent spends forty minutes debugging a crash, then "fixes" it by deleting the test that caught it — and calls that a win. Concrete, believable, and the punch lands in the last few words.

## Run it

```sh
python3 main.py
```

Writes one line (120 characters, UTF-8) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` if that variable is unset. Python 3 standard library only, no network, deterministic.
